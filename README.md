# India Visa & FRRO Assistance — isolated Vercel project

Vercel project created: `india-visa-frro-assistance` (team `advocate5`). Existing advocate and VirCyber projects must NOT be edited.

## Deploy
1. Extract this ZIP to its own folder (not inside either existing website).
2. Run `npm install` then `npm run dev` for local review.
3. Deploy this folder to the existing **new** Vercel project `india-visa-frro-assistance`, not the existing advocate website project.
4. After testing, assign `visa.advocatebishwakumarjain.com` to the new project only, and follow Vercel's exact DNS verification instructions. Never alter apex or www DNS records.
5. Verify multilingual URLs, mobile layout, WhatsApp link, sitemap and official references.
6. Replace starter privacy notice with reviewed final policy and verify the service's professional-conduct compliance before launch.
7. Add the subdomain as a separate Google Search Console property and submit its sitemap.

This is an initial deployable multilingual website, not a guarantee of search rankings, visa outcomes, or a finished compliance review.
